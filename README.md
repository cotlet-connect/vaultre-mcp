# How to connect VaultRE to Claude Code, ChatGPT and any AI agent

**Yes, ChatGPT, Claude and other AI agents can work in your VaultRE account.** Cotlet.dev connects your own signed-in VaultRE account to any AI agent, so you can ask in plain words and the AI manages enquiries, contacts, properties and viewings for you.

## What you can ask

> List all new VaultRE enquiries from realestate.com.au and show the property and possible duplicate contact.

> Process Priya Nair's enquiry for 14 Wattle Street and add a buyer requirement for the property.

> Find contacts in the sales department whose email contains example.com and add a note to Priya's record.

> Show this week's open homes and schedule a viewing for Alex Morgan on Saturday at 11 am.

> Give me a weekly report of appraisals, listings and upcoming viewings for the sales team.

## Connect in 2 minutes

Get your API key at https://cotlet.dev/app and export it as `COTLET_API_KEY`.

### Claude Code

```bash
claude mcp add --transport http cotlet https://cotlet.dev/mcp/v1 --header "Authorization: Bearer $COTLET_API_KEY"
```

### ChatGPT

Settings → Apps → add connector URL `https://cotlet.dev/mcp/v1`, then sign in with Cotlet.dev. No API key needed.

### Cursor

Copy `.cursor/mcp.json` from this repo into your project:

```json
{
  "mcpServers": {
    "cotlet": {
      "url": "https://cotlet.dev/mcp/v1",
      "headers": {
        "Authorization": "Bearer ${COTLET_API_KEY}"
      }
    }
  }
}
```

## Run it locally (stdio)

This repo is a real MCP server. It speaks MCP over stdio, lists its VaultRE tools without any key, and forwards every tool call to the hosted Cotlet.dev server. The hosted URL above stays the recommended way. Use this when your client only starts local servers.

```json
{"mcpServers":{"vaultre":{"command":"uvx","args":["vaultre-mcp"],"env":{"COTLET_API_KEY":"your-key"}}}}
```

Or with Docker:

```bash
docker build -t vaultre-mcp .
docker run -i --rm -e COTLET_API_KEY vaultre-mcp
```

Tools: `vaultre_guide`, `vaultre_status`, `vaultre_open`, `vaultre_read`, `vaultre_click`, `vaultre_type`, `vaultre_close`. Without `COTLET_API_KEY` a tool call answers: "Set COTLET_API_KEY. Get a key at https://cotlet.dev/app".

## Command line

Python 3.10+, nothing else to install. From PyPI:

```bash
pip install vaultre-mcp        # or run it once: uvx vaultre-mcp connect
vaultre-mcp connect
```

Or straight from this repo:

```bash
export COTLET_API_KEY="your-key"
python3 vaultre_agent.py connect   # ready config for Claude Code, Cursor, ChatGPT
python3 vaultre_agent.py status    # is VaultRE ready in your Cotlet.dev account
python3 vaultre_agent.py guide     # VaultRE screens and sign-in link
python3 vaultre_agent.py read      # open VaultRE, read the page, close the browser
python3 vaultre_agent.py tools     # list Cotlet.dev tools
python3 vaultre_agent.py serve     # start the stdio MCP server (same as no argument)
```

## Questions from VaultRE users

**Does VaultRE have an API?**

VaultRE, now sold as MRI Vault, has an API for approved developers, but no official MCP server (checked 27 Oct 2026). Cotlet.dev works in your own signed-in VaultRE account, so your AI agent can manage enquiries and property workflows with no API key and no code.

**How do I connect VaultRE to ChatGPT?**

Add Cotlet.dev as an app in ChatGPT with the connector URL `https://cotlet.dev/mcp/v1`, sign in to VaultRE once in your Cotlet.dev Cloud Browser, and ask ChatGPT in plain words.

**Is there a way to use Claude with VaultRE?**

Yes. In Claude Code run the one-line `claude mcp add` command above; in the Claude app add `https://cotlet.dev/mcp/v1` as a custom connector. Claude then works in your own VaultRE account.

**Is there a VaultRE MCP server?**

VaultRE has no official MCP server. Cotlet.dev is a hosted MCP server that works in VaultRE with ChatGPT, Claude, Cursor, Codex, n8n, Make and scripts.
